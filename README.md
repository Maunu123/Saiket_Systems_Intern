# Saiket Systems Internship Tasks

A structured collection of six beginner-friendly full-stack tasks.

## Projects

1. `task-1-portfolio` - responsive portfolio with Projects section and contact validation.
2. `task-2-storefront` - responsive e-commerce landing page with product filtering, cart count, and newsletter validation.
3. `task-3-react-todo` - React + Vite task manager with add, edit, delete, completion, and filters.
4. `task-4-rest-api` - Express CRUD API for users with an in-memory store.
5. `task-5-database-api` - Express CRUD API backed by PostgreSQL using parameterized SQL.
6. `task-6-full-stack` - full-stack user management system with Express, PostgreSQL, and a browser frontend.

## Quick start

- Open `task-1-portfolio/index.html` or `task-2-storefront/index.html` directly in a browser.
- For the React app: `cd task-3-react-todo`, `npm install`, then `npm run dev`.
- For either API: `cd task-4-rest-api` or `cd task-5-database-api`, `npm install`, then `npm run dev`.
- For the full-stack app, create a PostgreSQL database, copy `.env.example` to `.env`, run `npm install`, then `npm run dev` in `task-6-full-stack`.

The database projects include `schema.sql` and Postman-ready endpoint notes in their READMEs.
