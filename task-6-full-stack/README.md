# Task 6: Full-Stack User Management System

This project combines a PostgreSQL database, Express REST endpoints, and a responsive browser UI.

## Run

1. Create the `internship` PostgreSQL database.
2. Run `schema.sql`.
3. Copy `.env.example` to `.env` and set `DATABASE_URL`.
4. Run `npm install` and `npm run dev`.
5. Open `http://localhost:4002`.

The UI supports add, view, edit, and delete operations through `/api/profiles`.
