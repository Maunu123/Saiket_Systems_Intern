# Task 5: PostgreSQL Database Integration

Create a PostgreSQL database named `internship`, run `schema.sql`, copy `.env.example` to `.env`, then:

```bash
npm install
npm run dev
```

The API runs at `http://localhost:4001`. Every query uses PostgreSQL parameters (`$1`, `$2`, etc.) to avoid SQL injection. Test the same CRUD routes as Task 4 in Postman.
